\addcontentsline{toc}{chapter}{Prefacio}

Este documento sirve a la vez como ejemplo terminado y como plantilla reutilizable para apuntes de cualquier tema. El contenido de muestra trata geometría hiperbólica para que puedas comparar capítulos, figuras, fórmulas, bibliografía, referencias cruzadas, índice y apéndices en un proyecto que compila.

La estructura editorial se conserva deliberadamente como la de un libro: hay portada, preliminares, capítulos y material de consulta. La intención, sin embargo, es que estas páginas funcionen como notas personales que puedan crecer de manera incremental. El primer capítulo enseña comandos básicos de LaTeX; el apéndice de uso explica cómo sustituir el ejemplo por tus propios temas.

La exposición es introductoria y no pretende reemplazar los textos citados. Las referencias al final ofrecen rutas de lectura desde geometría no euclidiana elemental hasta superficies hiperbólicas. Las soluciones seleccionadas se incluyen para mostrar cómo enlazar los problemas del cuerpo con un apéndice.
