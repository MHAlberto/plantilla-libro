\chapter{Primeros pasos: comandos y notación}
\label{cap:comandos-basicos}

Este capítulo presenta comandos básicos de LaTeX mientras introduce el lenguaje geométrico que se usará en los apuntes. La geometría hiperbólica estudia una geometría de curvatura negativa; servirá como hilo conductor y como ejemplo de cómo organizar un documento. Para una introducción sistemática, véanse \cite{greenberg2008,anderson2005}.

\section{Estructura del texto}

Los archivos se componen de comandos y texto. El signo de porcentaje inicia un comentario: el compilador ignora el resto de esa línea. Los comandos de sección llevan el texto del encabezado entre llaves.

\begin{verbatim}
\chapter{Título del capítulo}
\section{Título de la sección}
\subsection{Título de la subsección}
\end{verbatim}

Para empezar un párrafo, deja una línea en blanco en el archivo. Usa \verb|\emph{texto}| para dar énfasis y \verb|\textbf{texto}| para negritas. Las listas se escriben con \verb|itemize| o \verb|enumerate|:

\begin{itemize}
  \item El disco de Poincaré es un modelo del plano hiperbólico.
  \item Sus geodésicas parecen líneas o arcos de círculo en el dibujo.
\end{itemize}

\section{Comandos matemáticos}

Las expresiones cortas se escriben entre \verb|\(| y \verb|\)|, por ejemplo, \(z\in\mathbb{C}\). Para una ecuación centrada y numerada usa el entorno \verb|equation|:

\begin{equation}
  \mathbb{D}=\{z\in\mathbb{C}:|z|<1\}.
  \label{eq:disco-unitario}
\end{equation}

Algunos comandos frecuentes son:

\begin{itemize}
  \item \verb|\frac{a}{b}| para fracciones.
  \item \verb|\sqrt{x}| para raíces.
  \item \verb|\sum_{k=1}^{n}| para sumas.
  \item \verb|\mathbb{R}| para los números reales.
\end{itemize}

En el texto se vería, por ejemplo, \(\frac{x^2}{1-x^2}\).

\section{Etiquetas y referencias}

Pon una etiqueta única después del elemento que quieres citar. \verb|\ref| inserta su número y \verb|\cref| añade el nombre del tipo de elemento. Para la ecuación \cref{eq:disco-unitario}, la etiqueta es \verb|eq:disco-unitario|.

\begin{verbatim}
\section{Una sección}
\label{sec:ejemplo}

Consulta la \cref{sec:ejemplo} y la \eqref{eq:disco-unitario}.
\end{verbatim}

Usa nombres únicos y descriptivos, con prefijos como \verb|cap:|, \verb|sec:|, \verb|eq:| y \verb|fig:|. \verb|\label| no crea una referencia por sí solo: se combina con \verb|\ref|, \verb|\eqref| o \verb|\cref|.

\section{Definiciones y resultados}

La clase trae entornos opcionales para organizar conceptos y argumentos. Por ejemplo:

\begin{definition}[Geodésica]
Una geodésica es una curva que localmente minimiza la longitud entre puntos cercanos.
\end{definition}

\begin{example}
En el modelo del disco, un diámetro es una geodésica.
\end{example}

Para otros usos consulta el \cref{ap:guia-uso}, donde se listan los entornos disponibles y se explica cómo añadir capítulos, figuras, citas e índices.

\section{Figuras guardadas en la carpeta de recursos}

Los dibujos TikZ se guardan en archivos separados dentro de \texttt{assets/tikz}. Así el capítulo conserva el texto y cada ilustración se puede mantener o reutilizar aparte. La \cref{fig:tikz-incrustado} se obtiene insertando un archivo externo:

\begin{verbatim}
\begin{figure}[htbp]
  \centering
  \input{assets/tikz/disco-poincare}
  \caption{Diámetro y arco geodésico en el disco de Poincaré.}
  \label{fig:ejemplo-en-codigo}
\end{figure}
\end{verbatim}

\section{Citas e índice}

Las fuentes viven en \texttt{bibliografia.bib}. Cita una clave con \verb|\cite{anderson2005}|, como en esta frase \cite{anderson2005}. Biber arma la lista de referencias durante la compilación.

Para agregar una entrada al índice de palabras, usa \verb|\index{geodésica}| después de la palabra. Aquí se registra el \index{disco de Poincaré}disco de Poincaré como ejemplo.
